# AI Study Buddy

A personalized learning platform that allows users to upload study materials (PDFs, notes) and automatically generate:

- Topic-wise summaries
- Key takeaways
- Flashcards (Q&A)
- Quiz questions

This project uses **Flask** for the backend, **OpenAI GPT** for AI content generation, and a simple **HTML/CSS/JS frontend**.

---

## Features

1. **Upload PDF**: Users can upload PDF notes to generate learning resources.
2. **Dynamic AI Content**: Generates topic-wise summaries, key takeaways, flashcards, and quizzes using OpenAI GPT.
